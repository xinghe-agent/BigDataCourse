# 大数据采集与处理

## 项目简介

本仓库用于存放《大数据采集与处理》课程的实验代码及相关资料，主要使用 Python 进行数据采集、网页解析与数据预处理等操作。

## 项目结构

```text
BigDataCourse/
├── Lab01-No-xinghe/    # 实验一
├── Lab02-No-xinghe/    # 实验二
├── Lab03-No-xinghe/    # 实验三
└── Lab04-No-xinghe/    # 实验四
```

## 开发环境

- 操作系统：Windows
- 编程语言：Python
- 开发工具：VS Code、Jupyter Notebook
- Python 环境管理：Miniconda

## 使用说明

1. 克隆本仓库到本地：

   ```bash
   git clone https://github.com/xinghe-agent/BigDataCourse.git
   ```

2. 根据实验编号进入对应文件夹。
3. 使用 Jupyter Notebook 或 VS Code 打开 `.ipynb` 文件。
4. 根据实验要求运行代码，查看实验结果。

## 说明

各实验文件夹独立存放对应的实验代码、数据文件及实验报告，便于分类管理和后续查阅。
